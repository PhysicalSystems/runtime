# Security policy

Do not report vulnerabilities in a public issue. Send a private report through
GitHub Security Advisories for this repository, including affected versions,
reproduction steps, impact and any suggested mitigation.

Runtime's fail-closed Python lifecycle is not a physical safety certification.
Security reports involving a TinyEdge hosted service, device credential,
private adapter or customer environment should be sent through the private
TinyEdge support channel instead of this public repository.

The currently supported line is `0.x`. Security fixes may require consumers to
upgrade to the newest pre-1.0 minor version.
